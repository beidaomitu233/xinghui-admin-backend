# 邮件模块分析

## 一、模块概览

RuoYi-Vue-Plus 的邮件模块基于 **Hutool Mail** + **Jakarta Mail API** 实现，提供简洁易用的邮件发送能力。

### 1.1 模块位置

```
ruoyi-common-mail/
├── pom.xml
└── src/main/
    ├── java/org/dromara/common/mail/
    │   ├── config/
    │   │   ├── MailConfig.java                    # 自动配置类
    │   │   └── properties/
    │   │       └── MailProperties.java            # 配置属性类
    │   └── utils/
    │       └── MailUtils.java                     # 邮件工具类
    └── resources/META-INF/spring/
        └── org.springframework.boot.autoconfigure.AutoConfiguration.imports
```

### 1.2 技术栈

- **Hutool Mail**（简化 JavaMail API）
- **Jakarta Mail API**（jakarta.mail，Java EE 迁移到 Eclipse 后的新命名）
- **Spring Boot AutoConfiguration**（自动配置）

## 三、核心组件详解

### 3.1 MailProperties（配置属性类）

```java
@Data
@ConfigurationProperties(prefix = "mail")
public class MailProperties {
    private Boolean enabled;           // 开关
    private String host;               // SMTP服务器
    private Integer port;              // 端口
    private Boolean auth;              // 是否需要认证
    private String user;               // 用户名
    private String pass;               // 密码/授权码
    private String from;               // 发件人 (支持 RFC-822 格式)
    private Boolean starttlsEnable;    // STARTTLS 加密
    private Boolean sslEnable;         // SSL 加密
    private Long timeout;              // SMTP超时(毫秒)
    private Long connectionTimeout;    // Socket连接超时(毫秒)
}
```

**配置项说明**:

| 属性 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| enabled | Boolean | 邮件功能开关 | false |
| host | String | SMTP 服务器地址 | smtp.163.com |
| port | Integer | SMTP 端口 | 465 (SSL) / 25 (普通) |
| auth | Boolean | 是否需要用户名密码验证 | true |
| user | String | SMTP 用户名 | xxx@163.com |
| pass | String | SMTP 密码/授权码 | xxxxxxxxxx |
| from | String | 发件人地址 (RFC-822) | xxx@163.com 或 名称 <xxx@163.com> |
| starttlsEnable | Boolean | STARTTLS 加密 | true |
| sslEnable | Boolean | SSL 加密 | true |
| timeout | Long | SMTP 操作超时 (毫秒) | 0 (不超时) |
| connectionTimeout | Long | Socket 连接超时 (毫秒) | 0 (不超时) |

### 3.2 MailConfig（自动配置类）

```java
@AutoConfiguration
@EnableConfigurationProperties(MailProperties.class)
public class MailConfig {

    @Bean
    @ConditionalOnProperty(value = "mail.enabled", havingValue = "true")
    public MailAccount mailAccount(MailProperties mailProperties) {
        MailAccount account = new MailAccount();
        account.setHost(mailProperties.getHost());
        account.setPort(mailProperties.getPort());
        account.setAuth(mailProperties.getAuth());
        account.setFrom(mailProperties.getFrom());
        account.setUser(mailProperties.getUser());
        account.setPass(mailProperties.getPass());
        account.setSocketFactoryPort(mailProperties.getPort());
        account.setStarttlsEnable(mailProperties.getStarttlsEnable());
        account.setSslEnable(mailProperties.getSslEnable());
        account.setTimeout(mailProperties.getTimeout());
        account.setConnectionTimeout(mailProperties.getConnectionTimeout());
        return account;
    }
}
```

**设计原理**:

| 注解 | 作用 |
|------|------|
| @AutoConfiguration | Spring Boot 3.x 自动配置注解 |
| @EnableConfigurationProperties | 启用 MailProperties 配置绑定 |
| @ConditionalOnProperty | 仅当 mail.enabled=true 时才创建 Bean，实现按需加载 |

#### 3.3.2 底层核心方法

```java
private static String send(MailAccount mailAccount, boolean useGlobalSession,
    Collection<String> tos, Collection<String> ccs, Collection<String> bccs,
    String subject, String content, Map<String, InputStream> imageMap,
    boolean isHtml, File... files) {
    
    final JakartaMail mail = JakartaMail.create(mailAccount).setUseGlobalSession(useGlobalSession);
    
    // 设置抄送人
    if (CollUtil.isNotEmpty(ccs)) {
        mail.setCcs(ccs.toArray(new String[0]));
    }
    // 设置密送人
    if (CollUtil.isNotEmpty(bccs)) {
        mail.setBccs(bccs.toArray(new String[0]));
    }
    
    mail.setTos(tos.toArray(new String[0]));
    mail.setTitle(subject);
    mail.setContent(content);
    mail.setHtml(isHtml);
    mail.setFiles(files);
    
    // 处理内嵌图片
    if (MapUtil.isNotEmpty(imageMap)) {
        for (Entry<String, InputStream> entry : imageMap.entrySet()) {
            mail.addImage(entry.getKey(), entry.getValue());
            IoUtil.close(entry.getValue());  // 自动关闭流
        }
    }
    
    return mail.send();  // 返回 message-id
}
```

## 六、实际使用场景

### 6.1 验证码邮件发送（核心场景）

**文件位置**: `ruoyi-admin/controller/CaptchaController.java`

```java
@GetMapping("/resource/email/code")
public R<Void> emailCode(@NotBlank(message = "{user.email.not.blank}") String email) {
    // 1. 检查邮件功能是否启用
    if (!mailProperties.getEnabled()) {
        return R.fail("当前系统没有开启邮箱功能！");
    }
    // 2. 调用独立方法 (绕过AOP代理确保限流生效)
    SpringUtils.getAopProxy(this).emailCodeImpl(email);
    return R.ok();
}

@RateLimiter(key = "#email", time = 60, count = 1)  // 每分钟限1次
public void emailCodeImpl(String email) {
    // 1. 生成4位随机验证码
    String code = RandomUtil.randomNumbers(4);
    // 2. 存入Redis，设置过期时间
    String key = GlobalConstants.CAPTCHA_CODE_KEY + email;
    RedisUtils.setCacheObject(key, code, Duration.ofMinutes(Constants.CAPTCHA_EXPIRATION));
    // 3. 发送邮件
    try {
        MailUtils.sendText(email, "登录验证码", 
            "您本次验证码为：" + code + "，有效性为" + Constants.CAPTCHA_EXPIRATION + "分钟，请尽快填写。");
    } catch (Exception e) {
        log.error("验证码邮件发送异常 => {}", e.getMessage());
        throw new ServiceException(e.getMessage());
    }
}
```

**流程**:
```
用户请求 → 检查开关 → 限流校验 → 生成验证码 → 存Redis → 发送邮件 → 返回结果
```

### 6.2 邮箱登录认证

**文件位置**: `ruoyi-admin/service/impl/EmailAuthStrategy.java`

```java
@Service("email" + IAuthStrategy.BASE_NAME)  // Bean名称: "emailAuthStrategy"
public class EmailAuthStrategy implements IAuthStrategy {

    @Override
    public LoginVo login(String body, SysClientVo client) {
        // 1. 解析请求体
        EmailLoginBody loginBody = JsonUtils.parseObject(body, EmailLoginBody.class);
        ValidatorUtils.validate(loginBody);
        
        // 2. 根据邮箱加载用户
        SysUserVo user = loadUserByEmail(loginBody.getEmail());
        
        // 3. 校验邮箱验证码 (从Redis获取)
        loginService.checkLogin(LoginType.EMAIL, tenantId, user.getUserName(), 
            () -> !validateEmailCode(tenantId, email, emailCode));
        
        // 4. 构建登录用户并生成Token
        LoginUser loginUser = loginService.buildLoginUser(user);
        LoginHelper.login(loginUser, model);
        return loginVo;
    }

    private boolean validateEmailCode(String tenantId, String email, String emailCode) {
        String code = RedisUtils.getCacheObject(GlobalConstants.CAPTCHA_CODE_KEY + email);
        if (StringUtils.isBlank(code)) {
            throw new CaptchaExpireException();  // 验证码过期
        }
        return code.equals(emailCode);
    }
}
```

## 七、异常处理机制

```java

if (!mailProperties.getEnabled()) {
    return R.fail("当前系统没有开启邮箱功能！");

```

### 7.3 发送层异常捕获

```java
// CaptchaController.java - try-catch 包裹
try {
    MailUtils.sendText(email, "登录验证码", "您本次验证码为：" + code + "...");
} catch (Exception e) {
    log.error("验证码邮件发送异常 => {}", e.getMessage());
    throw new ServiceException(e.getMessage());  // 转换为业务异常
}

// FlwCommonServiceImpl.java - 静默失败模式
try {
    MailUtils.sendText(emails, subject, message);
} catch (Exception ex) {
    log.error("【消息发送失败】类型={}，原因={}", messageTypeEnum, ex.getMessage(), ex);
    // 不抛出异常，确保主流程不受影响
}
```

### 7.4 可能抛出的异常类型

| 异常类型 | 触发场景 | 处理方式 |
|----------|----------|----------|
| NoSuchBeanDefinitionException | mail.enabled=false 时调用 MailUtils | 前置检查 mailProperties.getEnabled() |
| MailException (Hutool) | SMTP 连接失败、认证失败、网络异常 | try-catch 捕获 |
| ServiceException | 邮件发送失败时包装抛出 | 返回错误信息给前端 |
| CaptchaExpireException | 邮箱验证码过期 | 登录时校验抛出 |

## 十、技术选型优势

1. **Hutool 封装**: 简化了 JavaMail 的复杂 API，提供链式调用
2. **Jakarta Mail**: 使用最新的 Java EE 规范 (javax.mail -> jakarta.mail)
3. **Spring Boot 集成**: 自动配置 + 条件装配，开箱即用
4. **Redis 集成**: 验证码存储与过期管理
5. **限流保护**: @RateLimiter 防止邮件轰炸

## 十一、常见问题

### Q1: 邮件发送失败？
- 检查 mail.enabled 是否为 true
- 确认 SMTP 服务器地址和端口正确
- 验证用户名和授权码（注意：QQ/163 邮箱需使用授权码，非登录密码）
- 检查 SSL/TLS 配置是否匹配端口

### Q2: 如何开启邮件功能？
- 设置 `mail.enabled: true`
- 配置正确的 SMTP 服务器信息
- 重启应用

### Q3: 如何自定义发件人？
- 修改 `mail.from` 配置
- 支持 RFC-822 格式：`名称 <xxx@163.com>`

### Q4: 如何防止邮件轰炸？
- 使用 @RateLimiter 注解限流
- 验证码邮件默认 60 秒只能发送 1 次
